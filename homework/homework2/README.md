# Project Title  
**Stage 02: Tooling Setup**

## Project Purpose  
This homework sets up a reproducible Python project scaffold to prepare for later financial engineering tasks.  
The goal is to ensure that all code runs in an isolated environment, secrets are managed securely via `.env`,  
and Jupyter is available for interactive exploration.  

By the end of this stage, the repo will contain a clear folder structure, an environment file,  
and initial configuration code. This provides a consistent foundation for future development in  
data acquisition, preprocessing, modeling, and risk communication.
